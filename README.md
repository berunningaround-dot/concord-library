# Concord Library

Text-only searchable catalog of Concord Theatricals UK titles.

- Fully client-side search and filters
- Filters: type (Play/Musical), cast size, year ranges
- Large glyph symbols for visual orientation
- Data from Concord Theatricals perform catalog

Open `index.html` (or enable GitHub Pages) and load `data.json`.

Year data is premiere year where available from title pages.
